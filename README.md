# Loud + Cana public website

Responsive black-and-lime website with individual Home, Shop, Our Space, About, Membership, Contact and information pages. Static navigation uses hash URLs so direct links and refresh work on GitHub Pages.

Public catalog: https://carlosreynaga674-del.github.io/Cana/
Full application and real member accounts: https://loud-cana.onrender.com/

This self-contained website directs account signup and login to the full Render application. Source, the Node order/member service, deployment instructions and client package are on `loud-cana-client-handoff`. Persistent storage and approved business configuration are required for operational hosting and order intake.
