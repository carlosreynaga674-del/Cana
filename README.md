# Loud + Cana public website

Responsive black-and-lime catalog with dedicated pages and hash routes for direct links and refresh on GitHub Pages.

Public catalog: https://carlosreynaga674-del.github.io/Cana/
Full application: https://loud-cana.onrender.com/
Shared member/admin/staff login: https://loud-cana.onrender.com/login

The full application has member accounts, private ID/selfie staff review, a registered-member directory and persistent product publishing. New members remain restricted until actual manual review. No third-party identity service or automated liveness/face matching is connected.

This static catalog is a bundled snapshot and does not receive staff catalog changes automatically. Member signup/login link to the full application. Staff functions, private documents and real order intake require the full Node service with configured credentials, upload encryption and persistent storage. Source and the client ZIP are on loud-cana-client-handoff.
