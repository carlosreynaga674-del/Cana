# Loud + Cana public website

Responsive public catalog with dedicated pages and hash routes for direct links and refresh on GitHub Pages. Public staff navigation has been removed.

Public catalog: https://carlosreynaga674-del.github.io/Cana/
Full application: https://loud-cana.onrender.com/
Shared sign-in: https://loud-cana.onrender.com/login
Setup instructions: https://github.com/carlosreynaga674-del/Cana/blob/main/docs/STAFF_SETUP.md

The full service supports admin-created individual staff accounts and private manual ID/selfie application review. Dashboard access appears only after server authentication. No third-party identity service, automated face matching or liveness detection is connected.

This static catalog is a bundled snapshot and does not receive staff catalog changes automatically. Management, account access, identity uploads and order requests require the full Node service and its private hosting setup. Source and the complete client ZIP are on loud-cana-client-handoff.
